# Bird Species Observation Analysis
An interactive streamlit web application designed to analyze the distribution, diversity, and behavioral patterns of bird species across forest and grassland ecosystems using observational data from National Park Services administrative units.
---
## Project Overview
The primary objective of this project is to explore how environmental factors(such as temperature, humidity and vegetation types) influence bird populations and their behaviors. This application allows users to filter, visualize, and derive insights into wildlife conservation, land management, and biodiversity monitoring.
---
## Key Features
* **Interactive Filters:** Filter data dynamically by habitat type, season, data sheets, and observation years.
* **Key Performance Indicators (KPIs):** Real-time tracking of filtered records, active habitats, and included administrative units.
* **Visualizations:** Professional plotly sharts showcasing habitat distributions and temporal trends.
* **Actionable Insights:** Built-in business recommendations and observations targeted at wildlife conservation and habitat engagement.
* **Administrative Unit Guide:** Built-in reference for National Park Service site codes.
